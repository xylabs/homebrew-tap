# Homebrew Tap for XY Labs

Homebrew formulas for XY Labs CLI tools.

## Install

```sh
brew install xylabs/tap/xy
```

Or:

```sh
brew tap xylabs/tap
brew install xy
```

## Update

```sh
brew update && brew upgrade xy
```

## Available Formulas

| Formula | Description |
|---|---|
| `xy` | Unified TypeScript toolchain — build, lint, test, deploy |
